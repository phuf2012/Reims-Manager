USB passthrough

Attach a host USB device to the VM's XHCI bus or detach it to return it to Mint. A device leaving Mint confirms host capture, not that macOS detected it. Avoid passing through the keyboard or mouse you need to control Mint.

Safely eject USB storage in Mint before attaching it. If your account cannot open a device, Mint may request temporary access to that device only; unplugging removes it. No system rule is written.
